# AI助理概述

[!DNL GenStudio for Performance Marketing]透過模型內容通訊協定(MCP)連線到支援的AI助理。 連線後，您可以透過自然語言對話查詢廣告效益、組合創意和發佈核准的廣告。

## 支援的AI助理

您可以透過以下支援的AI助理路徑連線：

| AI助理 | 連線路徑 |
|---|---|
| Adobe CX Enterprise Coworker | 由您的組織管理的原生連線 |
| 克勞德 | 遠端MCP聯結器 |
| 網頁上的ChatGPT | 處於開發人員模式的遠端MCP聯結器 |
| 法典 | 從命令列設定的遠端MCP連線 |
| 作者 | 遠端MCP自訂聯結器 |
| Microsoft Copilot | 使用Microsoft指引設定的遠端MCP連線 |

請參閱[連線AI小幫手](connect-ai-assistants.md)以取得安裝程式指引。

## 功能

連線之後，AI助理可以在三個工作領域提供幫助：

- **深入分析：**&#x200B;取得標題KPI、尋找您表現最佳和最差的廣告、瞭解廣告以特定方式執行的原因，以及接收以您的績效資料為根據的建議。
- **建立：**&#x200B;瀏覽範本、組合範本或建議中的可編輯草稿，以及共用草稿以供檢閱和核准。
- **啟用：**&#x200B;尋找已核准的體驗、解析其發佈目標，並將其發佈至已連線的頻道。

支援的管道因功能而異。 深入分析涵蓋大部分報表的Meta、LinkedIn和Innovid。 自訂轉換量度涵蓋Meta和LinkedIn。

建立涵蓋Meta、LinkedIn、Display、TikTok和YouTube。 啟用封面Meta、LinkedIn和Google Campaign Manager 360。 如需每個工具的管道支援，請參閱[AI助理工具參考](tools-reference.md)。

## 存取權和許可權

AI助理功能通常可供啟用[!DNL GenStudio for Performance Marketing]的客戶使用。 您需要具有產品存取權的有效Adobe帳戶。

此連線使用您的Adobe身分識別，並尊重您現有的產品許可權。 您只能存取您的帳戶已可檢視的組織、付費媒體帳戶、行銷活動和資料。

每個連線的範圍皆為一個Adobe Identity Management System (IMS)組織。 重新連線，並在您需要切換時選取其他組織。
