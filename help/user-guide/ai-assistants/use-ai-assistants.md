# 使用AI助理

在您[連線AI助理](connect-ai-assistants.md)之後，使用自然語言提示來查詢效能資料、組合草稿，以及在[!DNL GenStudio for Performance Marketing]中發佈核准的廣告。

## 改善您的結果

以`In GenStudio for Performance Marketing`開始每個提示，以協助AI助理將您的要求路由到正確的工具。

指定您知道想要哪個管道時可使用的管道。 大部分深入分析提示會涵蓋Meta、LinkedIn或Innovid。 自訂轉換量度僅涵蓋Meta和LinkedIn。

建立提示涵蓋Meta、LinkedIn、Display、TikTok和YouTube。 啟動提示以涵蓋Meta、LinkedIn和Google Campaign Manager 360。

納入特定日期範圍以取得更精確的結果。 從廣泛的摘要開始，將請求限定為促銷活動或廣告，然後詢問創意屬性或建議。

## 檢閱績效總覽

要求管道和時段的標題量度：

- 「摘要我過去30天的Meta效能。 包括支出、CTR、CPC和CPM。」
- 「上個月與上個月相比，我的LinkedIn行銷活動表現如何？」
- 「提供本季無憂效能摘要。 突顯重大趨勢。」

## 探索行銷活動績效

詢問哪些行銷活動促成結果，以及哪些需要注意：

- 「列出上個月我的Meta行銷活動，依支出排序。」
- 「哪些LinkedIn行銷活動在上季的點進率最高？」
- 「顯示過去30天內高支出和低點進率的行銷活動。」

## 診斷廣告效益

識別高績效和低績效廣告，然後詢問是什麼造成了廣告結果：

- 「以上個月的點進率顯示前五個最高和最低表現的Meta廣告。」
- 「哪些LinkedIn廣告上一季的每次點按成本最低？」
- 「為什麼此廣告的表現優於類似的廣告？」
- 「顯示廣告標題、正文復本、call to action、資產和版位。」

當您提出後續問題時，請使用助理所傳回的廣告。 這可為助理員提供擷取正確詳細資料所需的識別碼。

## 依標籤分析效能

如果您的組織依產品、地區、對象或創意主題來標籤廣告，請在請求劃分前詢問可用的標籤類別：

- 「我的Meta廣告可以使用哪些標籤類別？」
- 「依產品標籤比較過去30天的LinkedIn成效。」
- 「哪個創意主題本季在Meta上的點進率最高？」

標籤分析需要在請求期間設定標籤和活動。

## 檢閱轉換量度

如果您的組織設定自訂轉換量度，請在請求值之前探索可用的量度：

- 「我的組織可以使用哪些自訂轉換量度？」
- 「顯示上個月我的Meta轉換量度。」
- 「哪些Meta行銷活動的合格潛在客戶成本最低？」

自訂轉換量度的可用性取決於您組織的設定。 這些量度支援Meta和LinkedIn。

## 請求創意建議

根據組織可用的效能資料來要求建議：

- 「哪些創意變化可以改善我表現最差的Meta廣告？」
- 「根據我的表現最佳者，建議改善LinkedIn點進率的方法。」
- 「顯示Meta的三項最高優先順序的創意建議。」
- 「說明此建議背後的效能證據。」

範圍狹窄的請求無法傳回任何建議。 視需要展開日期範圍或行銷活動範圍。

## 組合草稿廣告

將建議或範本轉換為可編輯的草稿：

- 「根據Meta建議建立草稿。」
- 「為我顯示Meta的快速範本。」
- 「此範本中可以變更哪些專案？」
- &quot;從此範本建立Meta廣告。 使用標題為「夏季優惠活動」和「call to action Shop Now」。 以下是創意簡介：[說明行銷活動、語調和選件]。」

>[!TIP]
>
>建立草稿會在Creative Cloud中成為真正的檔案。 這不是預覽。 先準備創意簡報並復本，再詢問。

## 檢閱和共用草稿

檢查草稿的狀態或邀請共同作業人員和稽核者：

- 「在GenStudio for Performance Marketing中顯示我最近的草稿。」
- 「此草稿的狀態為何？」
- 「以編輯者的身分與[電子郵件]共用此草稿。」
- 「傳送此草稿至[電子郵件]以供核准。」

## 發佈已核准的體驗

草稿獲得核准並發佈為體驗後，請發佈至連線的付費媒體頻道：

- 「顯示我對Meta核准的體驗。」
- 「為我的Meta廣告帳戶和行銷活動設定此體驗。」
- 「將此體驗發佈至LinkedIn。」

>[!IMPORTANT]
>
>發佈會建立即時廣告投放位置，並可能會產生廣告支出。 無法透過助理還原。 發佈前請確認目標帳戶、行銷活動和體驗。 重複此請求會建立另一個廣告。

## 解譯空白或無法使用的結果

空白結果並不一定表示連線有問題。 這可能表示沒有符合所選期間、管道、行銷活動或篩選器的列。

如果無法使用工具或量度，請詢問您的組織可以存取哪些[!DNL GenStudio for Performance Marketing]功能。 確認已設定相關的付費媒體帳戶或產品功能。
